# Jeremy's Configuration Files

This repo contains my config files for the following programs:

- Ghostty
- Tmux
- NeoVim
- Bash

## Setup

Clone the repo:

```bash
git clone git@github.com:jjcavallo5/dotfiles.git
```

Run the linking script:

```bash
cd dotfiles && ./link.sh
```

Open tmux with `ta`, then press `ctrl-a ctrl-I` to install TPM plugins
